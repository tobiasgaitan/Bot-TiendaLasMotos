## 3. Acciones de Mitigación Ejecutadas
1. **Filtro Parrot (Hard-Kill)**: Implementación de `re.sub(r'\b[Ee][Xx][Cc][Ee][Ll][Ee][Nn][Tt][Ee][:;\.,!\?]*\s*', '', text.strip())` en `ai_brain.py`.
2. **Bloqueo de Fase 1**: Inyección de instrucción prohibitiva en el System Prompt para impedir el protocolo de Habeas Data sin datos de Ciudad y Forma de Pago.
3. **Inyección Legal**: Automatización de la entrega del link de política de privacidad mediante detección de intención vía Regex.
4. **Validación de Suite de Pruebas**: Suite de `pytest` restaurada y aislada mediante Mocks (GCP/Vertex), logrando un estado de salida limpio (Exit Code: 0).
