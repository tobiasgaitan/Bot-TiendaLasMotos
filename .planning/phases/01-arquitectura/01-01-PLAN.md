# Plan 1-1: Crear SemanticCacheService

## Objective
Implementar el servicio de caché semántica que utiliza algoritmos locales puros (Fuzzy Matching con `difflib.SequenceMatcher`) para calcular la similitud de cadenas a velocidad de microsegundos, sin depender de llamadas de red (embeddings) ni librerías pesadas externas.

- `_calculate_similarity` debe usar la librería estándar de Python (`difflib`). Prohibido usar APIs externas o Gemini Embeddings.
- El almacenamiento debe ser 100% en RAM. No guardar en JSON en disco.
- El formato de respuesta almacenado y devuelto debe ser estrictamente el Markdown final (PCC Pro).
